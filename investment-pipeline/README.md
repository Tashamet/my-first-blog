# Veligera Capital — pipeline сделок (август 2026)

Материалы для партнёра по текущему пайплайну прямых сделок Pre-IPO:
OpenAI, Figure AI, 1X Technologies, Polymarket, Positron AI, Databricks,
VAST Data, ByteDance, Glean, Lightmatter, PsiQuantum, Waymo, Plata, Moonshot AI,
Higgsfield AI, Lambda.

| Файл | Назначение |
|---|---|
| `Veligera_Pipeline_OnePager.pdf` | Готовый документ для партнёра (6 стр., McKinsey-стиль): по каждой компании — суть, дизрапт, раунд/оценка, цена вторичного рынка, инвесторы, горизонт, доходность |
| `Veligera_Pipeline_OnePager.html` | Та же вёрстка в HTML: открывается в браузере и на телефоне, адаптируется под ширину экрана; печать из браузера даёт тот же A4-макет, что и PDF |
| `Veligera_Pipeline_Draft.docx` | Редактируемый Word-драфт того же содержания (структура + текст, без дизайна) |
| `Veligera_Pipeline_Upside_Model.xlsx` | Модель upside: лист на компанию, 3 сценария x 2 метода (мультипликаторы публичных аналогов и рыночные якоря), MOIC/IRR; жёлтые ячейки — изменяемые допущения |

Ключевые правила:

- **Оценка по последнему раунду** — post-money последнего закрытого раунда.
- **Цена на вторичном рынке** — индикативный диапазон фактических сделок и
  котировок площадок (Forge, Caplight, Nasdaq Private Market). Где котировок нет,
  применяется премия 8–15% к оценке раунда. Реальная цена определяется на момент
  сделки и предоставляется по запросу.
- Доходность считается от **середины диапазона** вторичного рынка; в one-pager
  вынесен **базовый** сценарий (среднее двух методов), консервативный и
  оптимистичный — в Excel.
- По **1X**, **Positron AI** и **Lambda** закрытые раунды устарели, поэтому расчёт
  идёт от оценки идущего раунда (1X — Series C ~$10 млрд, Positron — первый транш
  ~$3.5 млрд, Lambda — переговоры о раунде выше $12 млрд).
- По **Lambda** после даты отсечки объявлен контракт с Anthropic на ~$35 млрд
  (31.08.2026) и привлечён ещё $1 млрд долга. В расчёте это не учтено — при
  подтверждении сделки модель требует пересчёта.
- У **ByteDance** IPO отложено решением совета (май 2026), поэтому выход
  рассчитан через выкуп акций и блок-трейды, а не через листинг.
- По **Waymo, Plata, Moonshot AI и Higgsfield** подтверждённых котировок вторичного
  рынка нет: применена премия 8–15% к оценке последнего раунда, данные агрегаторов
  по этим компаниям противоречивы и в расчёте не использованы.
- **Moonshot AI** демонтирует офшорную структуру VIE по требованию китайского
  регулятора; механизм переноса прав зарубежных акционеров не определён, а для
  инвесторов из США действует Outbound Investment Security Program. Участие требует
  отдельной юридической проработки — это отражено в документе и в Excel.
- По **Waymo** мультипликатор к текущей выручке неприменим (250–350x), поэтому первый
  метод построен на прогнозной выручке года выхода. По **Higgsfield** расчёт идёт от
  независимой оценки выручки (Sacra), а не от заявленной компанией.
- Данные — публичные источники (Bloomberg, CNBC, TechCrunch, Sacra, Forge и др.)
  на 24.08.2026; ссылки на источники — внутри Excel и в research-заметках.

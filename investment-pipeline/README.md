# Veligera Capital — инвестиционный пайплайн (август 2026)

Материалы для партнёра по текущему пайплайну прямых сделок Pre-IPO:
Figure AI, Neuralink, Polymarket, 1X Technologies, OpenAI, Positron AI.

| Файл | Назначение |
|---|---|
| `Veligera_Pipeline_OnePager.pdf` | Готовый документ для партнёра (2 стр., McKinsey-стиль): по каждой компании — суть, дизрапт, раунд/оценка, вход, инвесторы, горизонт, upside |
| `Veligera_Pipeline_Draft.docx` | Редактируемый Word-драфт того же содержания (структура + текст, без дизайна) |
| `Veligera_Pipeline_Upside_Model.xlsx` | Модель upside: лист на компанию, 3 сценария x 2 метода (мультипликаторы публичных аналогов и рыночные якоря), MOIC/IRR; жёлтые ячейки — изменяемые допущения |

Ключевые правила:

- **Цена входа** во всех сделках индикативная: **+10% к оценке последнего закрытого
  раунда**; реальная цена определяется на момент сделки и предоставляется по запросу.
- По **1X** последний закрытый раунд (Series B, янв 2024, ~$0.82 млрд) устарел —
  upside считается от альтернативного входа по оценке идущего Series C (~$10 млрд +10%).
- Данные — публичные источники (Bloomberg, CNBC, TechCrunch, Sacra, Forge и др.)
  на 21.08.2026; ссылки на источники — внутри Excel и в research-заметках.

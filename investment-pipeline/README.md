# Veligera Capital — pipeline сделок (август 2026)

Материалы для партнёра по текущему пайплайну прямых сделок Pre-IPO:
OpenAI, Figure AI, 1X Technologies, Polymarket, Kalshi, Positron AI, Databricks.

| Файл | Назначение |
|---|---|
| `Veligera_Pipeline_OnePager.pdf` | Готовый документ для партнёра (2 стр., McKinsey-стиль): по каждой компании — суть, дизрапт, раунд/оценка, цена вторичного рынка, инвесторы, горизонт, upside |
| `Veligera_Pipeline_Draft.docx` | Редактируемый Word-драфт того же содержания (структура + текст, без дизайна) |
| `Veligera_Pipeline_Upside_Model.xlsx` | Модель upside: лист на компанию, 3 сценария x 2 метода (мультипликаторы публичных аналогов и рыночные якоря), MOIC/IRR; жёлтые ячейки — изменяемые допущения |

Ключевые правила:

- **Оценка по последнему раунду** — post-money последнего закрытого раунда.
- **Цена на вторичном рынке** — индикативный диапазон: котировки площадок
  (Forge, Caplight, Nasdaq Private Market) и оценки идущих раундов. Реальная цена
  определяется на момент сделки и предоставляется по запросу.
- Расчёт upside ведётся от **середины диапазона** вторичного рынка; в one-pager
  вынесен **целевой** сценарий (среднее двух методов), консервативный и
  оптимистичный — в Excel.
- По **1X** и **Positron AI** закрытые раунды устарели: цена определяется идущими
  раундами (1X — Series C ~$10 млрд, Positron — $3.5–5 млрд) и вторичным рынком.
- Данные — публичные источники (Bloomberg, CNBC, TechCrunch, Sacra, Forge и др.)
  на 24.08.2026; ссылки на источники — внутри Excel и в research-заметках.
